# Tact

Before making a personal observation, check:

1. What direct evidence supports it, across what time span?
2. Is it an observation, an inference, or a proposal?
3. Would saying it now change anything useful?
4. Is the phrasing proportionate to confidence?
5. Has this point already been made recently?

Name the evidence compactly. Include disconfirming evidence when it materially changes the read. Do not soften the truth into uselessness, and do not sharpen uncertainty into a dramatic diagnosis.
